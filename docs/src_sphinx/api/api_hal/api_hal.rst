Host High‑Level API Reference (HAL)
***********************************

The High‑Level API provides a hardware abstraction layer (HAL) for the Chimera‑SDK.

We currently support three categories of HAL objects:

- Communication interfaces (:cpp:type:`chi_interface_t`)
- Interrupt controllers   (:cpp:type:`chi_interrupt_t`)
- Accelerator devices     (:cpp:type:`chi_device_t`)
